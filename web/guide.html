Agent Guide

Live Call Text call ke dauran customer ki baat ko live text mein dikhata hai. Har qadam neeche asaan zaban mein likha hai.

1Headset aur window set-up

  • Hamesha headset lagayein, taake customer ki awaz aap ke mic mein na jaye.
  • Live Call Text ko alag Chrome window mein kholein aur WhatsApp ya dialer ke saath side-by-side rakhein (Windows + ← / →).
  • Customer speaks mein customer ki zaban chunein, aur I speak mein apni. Page ye choice yaad rakhta hai. Call ke beech bhi badal sakte hain.

2Browser wali WhatsApp

Jab call web.whatsapp.com (Chrome) se ho:

  1. Live Call Text par Start dabayein.
  2. Chrome ki chhoti window mein Chrome Tab chunein, phir WhatsApp wali tab par click karein.
  3. Also share tab audio on rehne dein, phir Share dabayein.
  4. Status Listening to a browser tab ho jayega. Customer ki baat "Customer" ke naam se aayegi.

3Install wali WhatsApp ya dialer

Jab call laptop mein install WhatsApp app ya VoIP dialer se ho:

  1. Pehli dafa: Windows Sound settings mein headset ko default device banayein.
  2. Start dabayein aur Entire screen chunein.
  3. Also share system audio ka tick zaroor lagayein, phir Share dabayein.
  4. Status Listening to the laptop's sound ho jayega.

Is tareeqe mein laptop ki har awaz suni jati hai. Call ke dauran gaana ya video band rakhein.

4Customer link kaise bhejein

  1. Call ke dauran Copy customer link dabayein.
  2. WhatsApp chat mein paste karke customer ko bhej dein.
  3. Customer link kholega to us ke phone par aap ki baat live likhi aayegi. Koi app ya sign-up nahi chahiye.
  4. Stop dabate hi link band ho jata hai aur customer ko "Call ended" dikhta hai. Har call ka link alag hota hai.

5Call ke baad chat save karein

  1. Call khatam ho to Stop dabayein.
  2. Save chat dabayein. Poori chat (waqt aur naam ke saath) ek text file ban kar laptop ke Downloads folder mein save ho jayegi.
  3. Agli call ke liye New call dabayein. Chat saaf ho jayegi aur nayi call khaali page se shuru hogi.

Agar chat save kiye baghair New call ya Start dabayein, to page poochega: Save and continue, Don't save ya Cancel. Is tarah record ghalti se gum nahi hota.

7Privacy

  • Call ki awaz kahin record ya save nahi hoti.
  • Text sirf aap ke khule page mein rehta hai. Page band karte hi khatam ho jata hai, siwaye us chat ke jo aap khud Save chat se laptop par save karein. Woh kahin upload nahi hoti.
  • Chrome ka free speech feature awaz ko text banane ke liye Google ko bhejta hai.
  • Customer ko batana chahein to keh sakte hain: "Is call ki baat-cheet ko live text mein dekha ja raha hai."
